- 2026-10-03 (M-01): Gap bounds keep the starter values (0.5 < gap_years < 2.5, strict). Note: a 6-month gap measures 181–184 days (0.496–0.504 years), so the 0.5 bound admits some 6-month leases and not others depending on the calendar months. M-02 reports how many pairs sit in that band; `sensitivity_min_gap_years: 0.45` admits all of them.
- 2026-10-03 (M-01): Growth is annualized as `ln(P_t / P_t-1) / gap_years` with `gap_years = days / 365.25` (contracts.DAYS_PER_YEAR), so a 365-day doubling reads ~100.1%/year rather than exactly 100%.
- 2026-10-03 (M-02): Real data check run (counts only, figures kept out of this log): every exclusion was `gap_too_short` (6-month band); no hUnit/safe-key mismatches and no non-positive rents. Admitting 6-month gaps (min 0.45) barely moves the plain medians, so the base bound has little effect. Counts are in notebook section 04.
- 2026-10-03 (M-03): StatCan WDS `releaseTime` is the latest release of each point, which for older months is a later re-release date (e.g. 2017–2019 points show 2021–2023). This errs on the safe side for leakage (data look available later than they were) and can only hide information from early backtest folds. Values are the current vintage; rent CPI is rarely revised.
- 2026-10-03 (M-03): December CPI is published mid-January, so at a Dec 31 cutoff the latest complete annual rent CPI change is for year y−2 (e.g. 2026 forecast sees 2024's +8.87% QC / +6.90% ON; 2025's change was released 2026-01-19).
- 2026-10-03 (M-03): Only the latest CMHC Rental Market Report (published 2025-12-11) is listed. Values repeated from earlier years carry that 2025 release date, so backtest cutoffs before 2025-12-11 see no CMHC value until older reports are added as separate pages.
- 2026-10-03 (M-03): Québec's pre-2026 TAL regime publishes component percentages, not one reference % for an unheated dwelling. The TAL page yields 2025/2026 "base rent" percentages under the new regime; mapping the regime properly is M-06. The Ontario guideline page states no announcement dates, so a human fills `release_date` during verification.
- 2026-10-03 (M-04): An asking rent posted in the 3 months up to a turnover's signing month is that lease's listing; the latest such asking is the one negotiated against. Asking rows are monthly snapshots of an open listing, not separate offers.
- 2026-10-03 (M-04): Listings in the 12 months before the cutoff stand for what the next year's turnovers will be asked; some of those units already re-leased before the cutoff, so the signal overlaps with recent turnover pairs (it is a leading indicator, not independent evidence).
- 2026-10-03 (M-04): Real data check run (counts/aggregates only, figures kept out of this log): most turnover segments use their own spread, the rest borrow the province pool; the median asking-to-signed spread is slightly negative (signed below asking) and stable across folds. The 2023 fold has no Ontario spread (the Ontario new-build first leased 2023) and uses the all-province spread.
- 2026-10-03 (M-03b): The Ontario guideline release dates are upper bounds (the statutory deadline). Actual announcements came earlier (around late June), so a cutoff between the announcement and Aug 31 would wrongly hide the value. This cannot happen at Dec 31 cutoffs.
- 2026-10-03 (M-03b): CMHC October 2020 values come from the 2021 report (released 2022-02-18), because the 2020 workbook is not on CMHC's asset server (404). This is conservative: those values became public about a year earlier. CMHC Ottawa turnover / non-turnover growth for October 2025 is NOT published as a percentage (the 2025 Table 6.0 gives rent levels only, and the report text says only "over 5 times the average rate"), so there is no row. CMHC same-sample data before October 2020 were not added.
- 2026-10-03 (M-03b): The TAL "estimation moyenne" (2019–2025) is an illustrative scenario for a dwelling with no tax change and no major work, not a cap. The 2026 "pourcentage de base" uses the new method and only covers notices given from 2026-01-01. Both are reference lines, not project renewal outcomes.

- 2026-10-03 (M-05): The naive figure is the year-over-year change of the median rent of ALL leases starting in the year (new leases and renewals together), which is what a simple reading of the extract gives. The composition part is a residual, so it also absorbs differences in gaps between leases and in winsorization, not only the mix.
