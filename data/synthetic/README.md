# FAKE DATA: these files are not project data

Every file in this folder is invented. None of it comes from the project CRM extract.

- The files are generated by `scripts/make_synthetic.py` from a fixed random seed. Running the script rebuilds them exactly.
- File names and columns copy the sponsor's format on purpose, so the code and the tests run without the confidential data.
- Buildings, units, rents, dates and concessions are made up. Each file has 32 to 170 rows, far fewer than the real extract.
- They are used only by the automated tests and by the dashboard's demo mode, which is labelled "synthetic demo" on screen.

The real project files are never committed. They stay in `data/private/`, which is gitignored, on each team member's machine.
