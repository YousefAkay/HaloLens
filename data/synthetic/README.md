# Fully invented fixtures

Every file in this folder is invented. None of it comes from real data.

- The files are generated by `scripts/make_synthetic.py` from a fixed random seed. Running the script rebuilds them exactly.
- File names and columns copy the source format on purpose, so the code and the tests run without any private data.
- Buildings, units, rents, dates and concessions are made up. Each file has 32 to 170 rows, far fewer than a real extract.
- They are used only by the automated tests and by the dashboard's demo mode, which is labelled "synthetic demo" on screen.

Real data files are never committed. They stay in `data/private/`, which is gitignored, on your own machine.
